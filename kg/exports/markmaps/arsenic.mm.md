# Arsenic et composés

## Identification

- N° CAS : `7440-38-2`
- Nom EN : Arsenic and compounds
- Catégorie : metal
- **CMR : C1A — cancérogène avéré**
- VLEP 8h : `0.01 mg/m³`
- [Fiche INRS](https://www.inrs.fr/risques/arsenic)

## Pathologies (4)

### Angiosarcome foie _(moderee / IARC-1)_

- Organes : Foie
- Tableaux MP : RG : RG-20, RG-20-BIS, RG-20-TER, RG-52, RG-52-BIS | RA : RA-10
- Surveillance : **Scanner thoracique** tous les 24 mois (INRS-2017 2017)

### Neuropathie arsenic _(neurologique / moderee / IARC-1)_

- Organes : Système nerveux
- Tableaux MP : RG : RG-20, RG-20-BIS, RG-20-TER | RA : RA-10
- Surveillance : **Dosage arsenic urinaire** tous les 12 mois (INRS-2019 2019)

### Cancer bronchique arsenic _(cancer / grave / IARC-1)_

- Organes : Poumon
- Tableaux MP : RG : RG-20, RG-20-BIS, RG-20-TER | RA : RA-10
- Surveillance : **Scanner thoracique** tous les 60 mois (HAS-2022 2022)

### Cancer cutane arsenic _(cancer / grave / IARC-1)_

- Organes : Peau
- Tableaux MP : RG : RG-20, RG-20-BIS, RG-20-TER | RA : RA-10
- Surveillance : **Examen dermatologique clinique** tous les 12 mois (INRS-2019 2019)
