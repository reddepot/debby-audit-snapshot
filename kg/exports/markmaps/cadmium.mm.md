# Cadmium et composés

## Identification

- N° CAS : `7440-43-9`
- Nom EN : Cadmium and compounds
- Catégorie : metal
- **CMR : C1B — cancérogène présumé**
- VLEP 8h : `0.001 mg/m³`
- [Fiche INRS](https://www.inrs.fr/risques/cadmium)

## Pathologies (3)

### Nephropathie cadmium _(moderee / IARC-1)_

- Organes : Rein
- Tableaux MP : RG : RG-61, RG-61-BIS
- Surveillance : **Dosage cadmium urinaire** tous les 12 mois (INRS-2020 2020)

### Osteomalacie cadmium _(moderee / IARC-1)_

- Organes : Os
- Tableaux MP : RG : RG-61, RG-61-BIS

### Cancer pulmonaire cadmium _(cancer / grave / IARC-1)_

- Organes : Poumon
- Tableaux MP : RG : RG-61, RG-61-BIS
- Surveillance : **Scanner thoracique** tous les 60 mois (HAS-2022 2022)

## Métiers exposés (3)

### Industrie (3)

- Metallurgiste _(modere)_
- Ouvrier batteries _(modere)_
- Soudeur brasure _(modere)_
