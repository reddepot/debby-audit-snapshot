# Chrome hexavalent (Cr VI)

## Identification

- N° CAS : `18540-29-9`
- Nom EN : Hexavalent chromium
- Catégorie : metal
- **CMR : C1A — cancérogène avéré**
- VLEP 8h : `0.001 mg/m³`
- VLEP court terme : `0.005 mg/m³`
- [Fiche INRS](https://www.inrs.fr/risques/chrome)
