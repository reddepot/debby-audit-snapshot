# Hydrocarbures aromatiques polycycliques (HAP, brais de houille)

## Identification

- Nom EN : Polycyclic aromatic hydrocarbons
- Catégorie : organique
- **CMR : C1A — cancérogène avéré**
- VLEP 8h : `0.15 mg/m³`
- [Fiche INRS](https://www.inrs.fr/risques/hap)

## Pathologies (3)

### Cancer bronchique hap _(cancer / grave / IARC-1)_

- Organes : Poumon
- Tableaux MP : RG : RG-16, RG-16-BIS
- Surveillance : **Scanner thoracique** tous les 60 mois (HAS-2022 2022)

### Cancer cutane hap _(cancer / grave / IARC-1)_

- Organes : Peau
- Tableaux MP : RG : RG-16, RG-16-BIS
- Surveillance : **Examen dermatologique clinique** tous les 12 mois (INRS-2020 2020)

### Cancer vessie hap _(cancer / grave / IARC-1)_

- Organes : Rein
- Tableaux MP : RG : RG-16, RG-16-BIS

### Industrie (3)
