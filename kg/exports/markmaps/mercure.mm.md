# Mercure et composés

## Identification

- N° CAS : `7439-97-6`
- Nom EN : Mercury and compounds
- Catégorie : metal
- **CMR : R1B — reprotoxique présumé**
- VLEP 8h : `0.02 mg/m³`
- [Fiche INRS](https://www.inrs.fr/risques/mercure)

## Pathologies (3)

### Intoxication mercurielle _(neurologique / moderee / IARC-2B)_

- Organes : Système nerveux
- Tableaux MP : RG : RG-2 | RA : RA-12
- Surveillance : **Dosage mercure urinaire** tous les 12 mois (INRS-2020 2020)

### Neuropathie mercure _(neurologique / moderee / IARC-2B)_

- Organes : Système nerveux
- Tableaux MP : RG : RG-2 | RA : RA-12
- Surveillance : **Examen neurologique clinique** tous les 12 mois (HAS-2021 2021)

### Tremblement intentionnel mercure _(neurologique / moderee / IARC-2B)_

- Organes : Système nerveux
- Tableaux MP : RG : RG-2 | RA : RA-12
