# Nickel et composés

## Identification

- N° CAS : `7440-02-0`
- Nom EN : Nickel and compounds
- Catégorie : metal
- **CMR : C1A — cancérogène avéré**
- VLEP 8h : `0.001 mg/m³`
- [Fiche INRS](https://www.inrs.fr/risques/nickel)

## Pathologies (3)

### Asthme nickel _(respiratoire / moderee / IARC-1)_

- Organes : Poumon
- Tableaux MP : RG : RG-37, RG-37-BIS, RG-37-TER
- Surveillance : **Épreuves fonctionnelles respiratoires (EFR)** tous les 12 mois (INRS-2017 2017)

### Eczema nickel _(cutanee / legere / IARC-1)_

- Organes : Peau
- Tableaux MP : RG : RG-37, RG-37-BIS, RG-37-TER

### Cancer naso sinusien nickel _(cancer / grave / IARC-1)_

- Organes : Voies aériennes supérieures
- Tableaux MP : RG : RG-37, RG-37-BIS, RG-37-TER
- Surveillance : **Scanner thoracique** tous les 60 mois (HAS-2022 2022)
- Surveillance : **Examen ORL (rhinoscopie, nasofibroscopie)** tous les 12 mois (INRS-2020 2020)
