# Poussières de bois (hêtre, chêne, exotiques)

## Identification

- Nom EN : Wood dust (hardwood)
- Catégorie : organique
- **CMR : C1A — cancérogène avéré**
- VLEP 8h : `1.0 mg/m³`
- [Fiche INRS](https://www.inrs.fr/risques/poussieres-bois)

## Pathologies (4)

### Adenocarcinome ethmoide _(moderee / IARC-1)_

- Organes : Voies aériennes supérieures
- Tableaux MP : RG : RG-47, RG-47-BIS | RA : RA-36, RA-47, RA-47-BIS, RA-47-TER
- Surveillance : **Examen ORL (rhinoscopie, nasofibroscopie)** tous les 24 mois (INRS-bois 2017)

### Asthme bois _(respiratoire / moderee / IARC-1)_

- Organes : Poumon
- Tableaux MP : RG : RG-47, RG-47-BIS | RA : RA-36, RA-47, RA-47-BIS, RA-47-TER
- Surveillance : **Épreuves fonctionnelles respiratoires (EFR)** tous les 12 mois (INRS-2017 2017)

### Dermatite bois _(cutanee / legere / IARC-1)_

- Organes : Peau
- Tableaux MP : RG : RG-47, RG-47-BIS | RA : RA-36, RA-47, RA-47-BIS, RA-47-TER

### Cancer naso sinusien bois _(cancer / grave / IARC-1)_

- Organes : Voies aériennes supérieures
- Tableaux MP : RG : RG-47, RG-47-BIS | RA : RA-36, RA-47, RA-47-BIS, RA-47-TER
- Surveillance : **Examen ORL (rhinoscopie, nasofibroscopie)** tous les 24 mois (INRS-bois 2017)
