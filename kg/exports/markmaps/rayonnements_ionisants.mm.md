# Rayonnements ionisants (X, gamma, neutron)

## Identification

- Nom EN : Ionizing radiation
- Catégorie : physique
- **CMR : C1A — cancérogène avéré**
- [Fiche INRS](https://www.inrs.fr/risques/rayonnements-ionisants)

## Pathologies (4)

### Cataracte radio induite _(moderee / IARC-1)_

- Tableaux MP : RG : RG-6

### Syndrome aigu irradiation _(moderee / IARC-1)_

- Tableaux MP : RG : RG-6

### Cancer thyroide radio induit _(cancer / grave / IARC-1)_

- Organes : Voies aériennes supérieures
- Tableaux MP : RG : RG-6

### Leucemie radio induite _(cancer / grave / IARC-1)_

- Organes : Moelle osseuse
- Tableaux MP : RG : RG-6
- Surveillance : **Numération formule sanguine + plaquettes** tous les 12 mois (Code-santé-publique-R1333 2023)
- Surveillance : **Dosimétrie passive (rayonnements ionisants)** tous les 12 mois (Code-santé-publique-R1333 2023)

## Métiers exposés (5)

### Industrie (2)

- Gammagraphe _(modere)_
- Industrie nucleaire _(modere)_

### Santé (3)

- Cardiologue interventionnel _(modere)_
- Manipulateur radio _(modere)_
- Radiologue _(modere)_
